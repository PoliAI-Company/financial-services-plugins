# Buyer List

description: 为卖方并购流程构建并整理潜在收购方名单。识别战略和财务买方，评估匹配度，并确定触达优先级。适用于准备卖方委托、构建买方名单，或评估潜在合作方。触发词包括 "buyer list"、"buyer universe"、"potential acquirers"、"who would buy this"、"strategic buyers" 和 "financial sponsors"。

## Workflow

### Step 1: 理解目标公司

- 公司描述、所属行业和商业模式
- Revenue、EBITDA 和增长画像
- 核心资产与能力，IP、客户关系、地域覆盖、团队
- 预期估值区间
- 卖方偏好，战略还是财务买方、管理层延续性、时间安排

### Step 2: 战略买方

按类别识别战略收购方：

**直接竞争对手**
- 与目标处于同一赛道、可提升市场份额的公司
- 逻辑：收入协同、消除竞争、扩大规模

**相邻赛道参与者**
- 在相邻市场经营、可延伸进入目标赛道的公司
- 逻辑：产品延伸、交叉销售、新市场进入

**纵向整合方**
- 可能进行纵向整合的客户或供应商
- 逻辑：掌控供应链、获取利润空间、形成战略锁定

**平台型收购方**
- 通过并购在该领域搭建平台的大型公司
- 逻辑：补强式收购、填补能力缺口

对每位战略买方，评估：

| Buyer | Sector | Revenue | Strategic Fit | Financial Capacity | M&A Track Record | Likelihood | Priority |
|-------|--------|---------|--------------|-------------------|------------------|------------|----------|
| | | | High/Med/Low | | Active/Moderate/None | | A/B/C |

### Step 3: 财务投资人

识别 PE 和其他财务买方：

**平台型投资人**
- 希望在该行业建立新平台的赞助方
- 标准：基金规模、行业聚焦、交易规模区间

**Add-on 买方**
- 已有现有被投组合公司，可将目标作为 bolt-on 收购的赞助方
- 明确对应的 portfolio company 以及协同逻辑

**Growth Equity**
- 适用于更早期或高增长目标
- 区分 minority 与 majority 偏好

对每位 sponsor：

| Sponsor | Fund Size | Sector Focus | Portfolio Overlap | Recent Activity | Priority |
|---------|-----------|-------------|-------------------|-----------------|----------|
| | | | | | A/B/C |

### Step 4: 优先级排序

对 buyer list 分层：

- **Tier 1 (5-10)**：战略匹配度最高、收购经验明确、逻辑清晰，优先联系
- **Tier 2 (10-15)**：匹配度不错，但逻辑没那么直接，第二轮联系
- **Tier 3 (10-20)**：存在可能性，但概率较低，如流程需要扩大范围再联系

### Step 5: 联系人映射

对每个 Tier 1 买方：
- 关键决策人，CEO、Corp Dev head、Partner
- 关系状态，既有关系、cold outreach、需要引荐
- 已知偏好或限制，规模、地域、结构
- 最合适的接触渠道

### Step 6: 输出

- Excel workbook，包含：
  - Strategic buyers 标签页，按 tier 排序
  - Financial sponsors 标签页，按 tier 排序
  - Tier 1 的联系人映射
  - 汇总统计，总买方数，按 tier 与按类型统计
- 用于 engagement letter 或 pitch 的单页 buyer universe 摘要

## Important Notes

- 质量优先于数量，聚焦且研究充分的 30 到 40 个买方，优于 200 个名字的长名单
- 研究近期并购活动，刚在该领域做过交易的买方，可能还想继续加码，也可能已无余力
- 对直接竞争对手要检查反垄断风险，并标记任何可能存在监管问题的对象
- 对财务 sponsor，要检查基金 vintage 和部署进度，接近投资期末尾的基金可能更有动力
- 一定要询问卖方，有没有希望纳入或排除的买方
- 随流程推进持续更新名单，根据反馈在不同 tier 之间调整买方
