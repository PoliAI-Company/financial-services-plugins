# Earnings Updates 的详细工作流

本文档提供 earnings update 流程各阶段的详细逐步说明。

## ⚠️⚠️⚠️ 关键警告：始终使用最新的业绩数据 ⚠️⚠️⚠️

**先停下来阅读这一节：**

训练数据是**过时的**。必须主动搜索并获取**最新**的业绩材料。使用过时业绩数据，是 earnings analysis 中最常见也最严重的错误。

**开始前：**
1. **检查今天日期** - 明确写下当前日期
2. **搜索最新材料** - 用 web search 找最近一期 earnings
3. **验证日期** - 确认 earnings release 在最近 3 个月内
4. **如果超过 3 个月** - 说明拿错季度了，必须重新搜索

## 阶段 1：业绩数据收集（30-60 分钟）

### 第 1 步：识别最新业绩周期

**CRITICAL**：始终搜索最新业绩，不要依赖 knowledge cutoff。
**CRITICAL**：绝不要直接使用训练中的 earnings data，那些已经过时。

**Step 1a: 搜索最新 Earnings Release**

**🚨 必须主动搜索——训练数据已经过时。🚨**

**MANDATORY STEP 1: 检查今天日期**
- **明确写下今天日期**：`[Month] [Day], [Year]`
- **用它来验证**你找到的 earnings 是否在最近 3 个月内
- **Example**："Today is October 29, 2024"

**MANDATORY STEP 2: 搜索 "LATEST EARNINGS"**
- 使用 web search，关键词例如：
  - `[Company name] latest earnings results`
  - `[Company name] most recent quarterly earnings`
  - `[Ticker symbol] earnings latest quarter`
- 或直接去公司 investor relations 站点：
  - `investor.[company].com` 或 `[company].com/investors`
  - 进入 "Press Releases"、"News" 或 "Earnings" 栏目
  - **按日期排序找到最新 release**
  - 搜索关键词："earnings"、"results"、"financial results"、"quarterly results"

**MANDATORY STEP 3: 验证发布日期**
- **查看找到的 earnings release 日期**
- **计算**：这个日期距今天是否在 3 个月以内？
- **如果是** → 进入下一步
- **如果不是**（超过 3 个月）→ 🚨 拿错季度，重新搜索

**❌ 常见错误：**
- ❌ 不搜索，直接使用训练数据里的 earnings
- ❌ 想当然地认为某个季度一定是最新，例如 "Q3 2024"
- ❌ 找到第一个业绩稿就用，不检查日期
- ❌ 不把发布日期和今天日期做比较
- ❌ 当 release 已经是 4 个月以上时仍继续

**✅ 正确做法：**
- ✅ 先检查今天日期
- ✅ 明确搜索 "latest" 或 "most recent"
- ✅ 阅读材料上的真实发布日期
- ✅ 确认该日期在最近 3 个月以内
- ✅ 如有任何不确定，用不同关键词重搜

**MANDATORY STEP 4: 确认季度**
- 阅读标题，确认 quarter 名称，Q1、Q2、Q3、Q4 或 fiscal quarter
- 阅读文档本身的发布日期
- 同时确认 quarter 与 date 都是最新的

3. **如果 IR 站点不清晰，可采用替代搜索方法：**
   - Web search: `[Company name] latest earnings results`
   - Web search: `[Company name] most recent quarterly earnings`
   - Web search: `[Ticker symbol] earnings latest quarter`
   - SEC EDGAR：搜索公司，并查看最新 10-Q 或 10-K 的 filing date

**能帮助找到最新数据的示例搜索：**
- "Nike latest earnings results"
- "AAPL most recent quarterly earnings"
- "Tesla Q3 2024 earnings"

**Step 1b: 理解公司的 Fiscal Calendar**

在通过搜索识别出最新季度后，要理解公司的 fiscal year 体系，避免误读季度。

**常见 fiscal year 模式：**
- **Calendar year (CY)**：Q1=Jan-Mar, Q2=Apr-Jun, Q3=Jul-Sep, Q4=Oct-Dec
- **Nike fiscal**：Q1=Jun-Aug, Q2=Sep-Nov, Q3=Dec-Feb, Q4=Mar-May
- **Apple fiscal**：Q1=Oct-Dec, Q2=Jan-Mar, Q3=Apr-Jun, Q4=Jul-Sep
- **Walmart fiscal**：Q1=Feb-Apr, Q2=May-Jul, Q3=Aug-Oct, Q4=Nov-Jan

很多公司会在 earnings release 标题处写明 fiscal year。必要时搜索 `[company] fiscal year calendar`。

**Step 1c: 强制验证——确认拿到的是最新数据**

🛑 **在完成以下所有检查之前，不要继续：**

- [ ] ✅ 已写下今天日期：`[Month] [Day], [Year]`
- [ ] ✅ 已主动搜索 "latest earnings" 或 "most recent earnings"
- [ ] ✅ 已找到 earnings release date：`[Month] [Day], [Year]`
- [ ] ✅ 已验证 release date 距今天在 3 个月以内
- [ ] ✅ 并未仅凭今天日期猜测季度
- [ ] ✅ 已看到真实 press release，确认该 quarter / period
- [ ] ✅ 已打开并阅读真实 earnings materials，而不是假设它们存在

**🚨 红旗信号——如果出现任意一条，说明季度拿错了：**
- 🚨 Release date 超过 90 天
- 🚨 依赖预期而不是搜索到的材料
- 🚨 根本没有看到任何 press release 或 filing 来确认该季度真实存在
- 🚨 使用了训练数据但没有搜索
- 🚨 说不出精确的 release date
- 🚨 找到的 release date 是 2023 或更早，而今天已经是 2024+

**IF ANY RED FLAGS PRESENT**：立即停止并重新搜索。不要用过时数据继续。

**Step 1c: 处理命名差异**

公司会使用不同术语，需识别以下模式：

**Quarter terminology：**
- "Q1 2024"、"Q1 FY24"、"First Quarter 2024"、"1Q24"
- "Third Quarter Fiscal 2024"、"Q3 FY2024"、"3Q FY24"

**Earnings release titles：**
- "[Company] Reports Q3 2024 Results"
- "[Company] Announces Third Quarter Fiscal 2024 Financial Results"
- "[Company] Q3 Revenue Grew 15% Year-over-Year"

**SEC filing searches：**
- 公司法定名称可能与常用名不同，例如 "Meta Platforms, Inc." vs "Facebook"
- 通过 ticker 搜索 filings 更稳定
- 对于 1-3 季，看最新 10-Q；对于 Q4，看 10-K

### 第 2 步：收集 Earnings Materials

在搜索并确认最新季度之后，收集以下材料：

**⚠️ IMPORTANT：必须搜索并访问真实文档，不要依赖训练数据。**

**Primary Materials（REQUIRED）：**
- **Earnings press release**
  - 通常位于公司 IR 站点的 "Press Releases" 或 "News"
  - 导航至 IR 站点，找到实际新闻稿
  - 搜索模式：`[Company name] latest earnings`、`[Company name] Q[X] [Year] earnings results`
  - 查找 PDF 或 HTML 版本
  - **验证日期与 Step 1 中的日期一致**
  - **阅读实际文档**，确认季度并提取 reported numbers

- **10-Q or 10-K filing**
  - 从 SEC EDGAR：`sec.gov/edgar/searchedgar/companysearch.html`
  - 使用 ticker 搜索
  - 对于 Q1-Q3：找最新 10-Q
  - 对于 Q4：找 10-K
  - 注意 filing 可能在 earnings release 后 1-5 天提交
  - 直链格式：`https://www.sec.gov/cgi-bin/viewer?accession=[accession-number]`

- **Earnings call transcript** - 🚨 **检查 transcript 日期** 🚨
  - 搜索：`[Company] latest earnings call transcript` 或 `[Company] Q[X] [Year] earnings call transcript`
  - **来源**：
    - 公司 IR 站点
    - Seeking Alpha
    - AlphaStreet、Motley Fool 等替代来源
  - **关键日期检查**：
    - ✅ 在使用 transcript 前，核对 transcript 本身的日期
    - ✅ transcript 日期必须与 Step 1 中的 release date 一致
    - ✅ 如果 transcript 写的是 "Q2 2023"，而 release 是 "Q3 2024"，则拿错了 transcript
    - 🚨 常见错误是随手拿了旧 transcript 却没核对日期
  - 如果 transcript 尚未发布，可听 webcast replay，或注明等待 transcript

**Supplemental Materials（如有）：**
- **Investor presentation / slides**
  - 常与 press release 一起发布在 IR 站点
  - 常命名为 "Q[X] [Year] Earnings Presentation" 或 "Investor Presentation"
  - 通常是 PDF

- **Supplemental data file**
  - 部分公司会提供详细指标的 Excel 文件
  - 常见名称："Supplemental Financial Information" 或 "Investor Data Sheet"

**Reference Materials（用于对比）：**
- **Prior quarter results**：用于 QoQ 对比
- **Prior year same quarter**：用于 YoY 对比
- **Prior estimates**：如果之前已覆盖该公司，查上一版预测
- **Consensus estimates**：来自 Bloomberg、FactSet、Refinitiv、Yahoo Finance
  - 关键：必须使用 earnings release 前的 consensus
  - 注意读取 "as of [date before earnings]"

**🛑 进入 Step 3 之前的强制核验：**

**日期校验：**
- [ ] ✅ 今天日期已写下
- [ ] ✅ Earnings release date：____________（必须在最近 3 个月内）
- [ ] ✅ Earnings call transcript date：____________（必须与 release date 相同或相差 1 天）
- [ ] ✅ 10-Q/10-K filing date：____________（必须属于同一季度）
- [ ] ✅ 所有材料显示的是同一季度，而不是混杂不同季度

**搜索与访问校验：**
- [ ] ✅ 已搜索 "latest earnings"
- [ ] ✅ 已访问真实 earnings press release 并阅读
- [ ] ✅ 已打开真实 earnings call transcript 并核验日期
- [ ] ✅ 已确认这确实是最新季度
- [ ] ✅ 已从真实材料中获得完整结果数据
- [ ] ✅ 已取得 earnings 前的 consensus estimates，且有来源日期

**🚨 红旗信号 - 若任意一项为真，立即停止：**
- 🚨 未实际搜索和访问 earnings materials
- 🚨 依赖记忆或训练数据而不是当前文档
- 🚨 Earnings release date 超过 90 天
- 🚨 无法说出准确的 earnings release 日期
- 🚨 Transcript 日期与 release date 不一致
- 🚨 材料显示不同季度
- 🚨 没核验日期就直接使用第一个搜索结果

### 第 4 步：从电话会中识别关键主题

阅读或收听 earnings call transcript，并记录：
- 管理层语气，confident、cautious 还是 defensive
- 反复强调的重点，产品发布、地域趋势、竞争等
- 分析师提问，投资者最担心什么
- Guidance 是上调、下调、维持还是首次给出
- 是否有意外评论或 surprise topics

## Phase 2: Analysis（2-3 小时）

### 第 5 步：Beat/Miss Analysis

对于每个超预期或低于预期的关键指标，解释：

**If BEAT：**
- 什么驱动了超预期？
- 是一次性因素还是可持续？
- 管理层是否上调了 forward guidance？
- 这会如何影响我们的 thesis？

**If MISS：**
- 哪个环节出了问题？
- 是 company-specific 还是 industry-wide？
- 管理层是否在采取修正措施？
- 这会如何影响我们的 thesis？

**Example Format：**
```
■ **Revenue Beat by 3% Driven by Strong DTC Performance**

Revenue of $13.5B exceeded our estimate of $13.1B by $400M (3%) and consensus
of $13.2B by $300M (2%). The outperformance was driven primarily by Direct-to-
Consumer channels, which grew 18% YoY (vs. our 12% estimate), offsetting
weaker-than-expected wholesale (-5% vs. flat estimate). Management cited strong
digital demand and successful product launches (Pegasus 40 running shoe, new
Jordan colorways) as key drivers. DTC now represents 42% of total revenue vs.
38% a year ago, demonstrating successful channel shift strategy.
```

### 第 6 步：Segment / Geographic / Product Analysis

按以下维度分析表现：
- Business segment，多分部公司
- Geography，North America、Europe、China 等
- Product category
- Channel，retail、wholesale、e-commerce

识别：
- 哪些部分超预期？
- 哪些部分低于预期？
- 与前几个季度相比趋势如何？
- 管理层对各部分 outlook 的评论是什么？

### 第 7 步：Margin Analysis

分析盈利能力：
- Gross margin：上升还是下降？为什么？
- Operating margin：上升还是下降？为什么？
- 关键驱动，定价、mix、成本、经营杠杆
- Forward outlook

### 第 8 步：Guidance Analysis

如果公司提供了 guidance：
- 将新 guidance 与 prior guidance 对比
- 与 internal estimates 和 Street estimates 对比
- 评估其可信度，公司是否有保守指引习惯，是否常 beat
- 识别 guidance 背后的关键假设

如果公司**没有**提供 guidance：
- 必须明确写出这一点
- 基于结果与管理层评论提供独立 outlook

### 第 9 步：Update Financial Model

更新以下预测：
- 当前财年，remaining quarters
- 下一财年
- 如有必要，也更新后一年

**务必清楚展示：**
```
UPDATED ESTIMATES:
─────────────────────────────────────────────────
                        Old Est     New Est     Change      Reason
FY2024E Revenue         $XX.XB      $XX.XB      +X.X%      [Brief reason]
FY2024E EBITDA          $X.XB       $X.XB       +X.X%      [Brief reason]
FY2024E EPS             $X.XX       $X.XX       +X.X%      [Brief reason]

FY2025E Revenue         $XX.XB      $XX.XB      +X.X%      [Brief reason]
FY2025E EBITDA          $X.XB       $X.XB       +X.X%      [Brief reason]
FY2025E EPS             $X.XX       $X.XX       +X.X%      [Brief reason]
```

### 第 10 步：更新估值与目标价

基于 updated estimates：
- 重新计算 DCF，使用更新后的 cash flows
- 更新 comparable company multiples，如 peer group 已披露业绩
- 确定新的 fair value
- 判断是否需要调整 price target

**Price Target Decision：**
- 如果 estimates 改变显著，>5%，通常应调整 PT
- 如果 estimates 仅边际变化，<5%，可考虑维持 PT
- 如果 thesis 明显增强 / 削弱，即使 estimates 变化不大，也可能需要调整 PT

### 第 11 步：评估 Rating Impact

判断是否调整 rating：
- 若 results 明显强于预期 + guidance 上调 → 考虑 upgrade
- 若 results 明显弱于预期 + guidance 下调 → 考虑 downgrade
- 若结果 inline 或偏 mixed → 通常维持 rating

**同时考虑：**
- 股票反应，up / down / flat
- Valuation，新 estimates 下是贵还是便宜
- Risk / reward 的非对称性是否改变

## Phase 3: Chart Generation（1-2 小时）

### 第 12 步：生成 8-12 张图

图表重点应放在**季度趋势**和**新增变化**上。

**REQUIRED CHARTS（共 8-12 张）：**
1. **Quarterly Revenue Progression**，柱状图
2. **Quarterly EPS Progression**，柱状图
3. **Quarterly Margin Trend**，折线图
4. **Revenue by Segment / Geography**，堆叠柱状图或表格
5. **Key Operating Metrics**，多折线图
6. **Beat/Miss Summary**，瀑布图或表格
7. **Estimate Revision Chart**，前后对比图
8. **Valuation Chart**，P/E 或 EV/EBITDA multiple

**OPTIONAL CHARTS：**
- Peer comparison
- Guidance vs. Street comparison
- Cash flow metrics
- Balance sheet highlights

**Chart Style Guidelines：**
- 重点展示**趋势**，季度进展
- 突出**变化**，beat / miss、预测修订
- 风格保持简单清晰，适用于 fast-turnaround report

## Phase 4: Report Creation（2-3 小时）

### 第 13 步：创建 DOCX 报告

使用 DOCX skill 创建 8-12 页报告。

详见 [report-structure.md](report-structure.md)，获取完整逐页模板和格式要求。

**关键步骤：**
1. 创建第 1 页，含 earnings summary 和 quick takeaways
2. 添加 detailed results analysis，第 2-3 页
3. 包含 key metrics 和 guidance，第 4-5 页
4. 更新 investment thesis，第 6-7 页
5. 提供 valuation 和 estimates，第 8-10 页
6. 如需要，添加 appendix，第 11-12 页
7. 全文嵌入 8-12 张图
8. 添加 1-3 张 summary tables
9. 包含完整 sources section，带 clickable hyperlinks

### 第 14 步：可选，更新 XLS 模型

如果这家公司已经有完整 financial model，可更新：
- Actual Q[X] results
- 修订未来季度预测
- 更新 valuation

**Note**：对 earnings updates 而言，完整 XLS 文件是**可选项**，不像 initiation reports 那样是强制项。DOCX 报告才是主要交付物。

如果创建 XLS，包含：
- Quarterly model tab
- Updated annual projections
- Revised DCF
- Updated comps analysis

## Phase 5: Quality Check & Delivery（30 分钟）

### 第 15 步：质量检查清单

发布前验证：

**Content：**
- [ ] beat / miss 表达清楚且已量化
- [ ] 已解释关键驱动，而不是只说 "strong performance"
- [ ] 已提供 updated estimates，并展示 old vs. new
- [ ] 已更新 price target 或明确说明维持不变
- [ ] 已确认或调整 rating，并给出理由
- [ ] 如有 guidance，已完成分析
- [ ] 已评估 thesis impact

**Formatting：**
- [ ] 第 1 页有 summary box 与 key bullets
- [ ] 所有 tables 都有 source lines
- [ ] 所有 figures 都有编号和标题
- [ ] Estimates table 展示 old vs. new
- [ ] 全文嵌入 8-12 张图
- [ ] 报告总长为 8-12 页

**Accuracy：**
- [ ] 数字与公司实际披露完全一致
- [ ] 数学计算无误
- [ ] ticker、company name、numbers 无拼写错误
- [ ] 图表与正文描述一致
- [ ] 日期为最新

**Citations：** ⭐ MANDATORY
- [ ] 每个 figure 都有具体来源、文档和日期
- [ ] 每个 table 都有具体文档引用
- [ ] beat/miss 分析标注 consensus source 及日期
- [ ] guidance changes 标注 current 和 prior guidance sources
- [ ] 关键统计数据带脚注，含具体页码 / slide 引用
- [ ] sources section 列出所有材料和 URLs
- [ ] 所有 URLs 都是 clickable hyperlinks
- [ ] 超链接已经测试且有效
- [ ] 所有 SEC filings 都链接到 EDGAR viewer
- [ ] 所有 earnings materials 均已超链接
- [ ] prior guidance 链接到上一季度材料
- [ ] 文中不显示 raw URLs
- [ ] earnings call 引用注明 speaker 和大致时间戳

**Timeliness：**
- [ ] 报告在 earnings release 后 24-48 小时内完成
- [ ] 所有数据均来自最新季度
- [ ] consensus estimates 来自 earnings 前，而非 earnings 后

### 第 16 步：交付报告

向用户提供：
1. **DOCX file**：`[Company]_Q[X]_[Year]_Earnings_Update.docx`
2. **Chart files**：全部 PNG / JPG charts，便于参考
3. **Optional XLS**：如维护了 financial model，则附上更新版本

**交付摘要：**
```
[Company] Q[X] [Year] Earnings Update Complete

Results: [BEAT / INLINE / MISS]
- Revenue: $X.XB ([beat/missed] by $XXM or X%)
- EPS: $X.XX ([beat/missed] by $X.XX)

Key Takeaways:
■ [Takeaway 1]
■ [Takeaway 2]
■ [Takeaway 3]

Updated Estimates:
- FY[Year]E Revenue: $XX.XB (prior: $XX.XB, [+/-]X%)
- FY[Year]E EPS: $X.XX (prior: $X.XX, [+/-]X%)

Rating: [MAINTAINED / RAISED / LOWERED] [RATING]
Price Target: $XXX (prior: $XXX) - [+/-]XX% upside

交付物：8-12 页的业绩更新报告，包含更新后的预估与估值。
```
