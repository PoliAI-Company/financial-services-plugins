# Equity Research Earnings Update

创建专业的 **EARNINGS UPDATE REPORTS**，用于分析已经处于覆盖范围内公司的季度业绩结果，并遵循机构级标准格式，参考 JPMorgan、Goldman Sachs、Morgan Stanley。

**关键特征：**
- **长度**：8-12 页
- **字数**：3,000-5,000 词
- **表格**：1-3 张摘要表，不是完整财务大表
- **图表**：8-12 张图
- **时效**：1-2 天，业绩后 24-48 小时内
- **读者**：已经熟悉公司的客户
- **重点**：新的信息，beat/miss、预测更新、论点影响
- **字体**：除非用户另行指定，否则所有文档统一使用 Times New Roman

## 何时使用

适用于用户请求：
- "Create an earnings update for [Company] Q3 2024"
- "Analyze [Company]'s quarterly results"
- "Post-earnings report for [Company]"
- "Q1/Q2/Q3/Q4 update for [Company]"

**以下情况不要使用：**
- 用户请求 "initiation report"，应使用其他 skill
- 用户请求 "flash note" 或 "quick take"，那是另一种格式
- 公司尚未纳入覆盖，需要先做 initiation

## 关键要求

### 1. 速度与时效性
- 在业绩发布后 24-48 小时内完成
- 只聚焦新信息
- 不要大段重复公司背景

### 2. Beat/Miss Analysis
- 开头就明确说明公司是 beat 还是 miss
- 量化偏差，例如 "Revenue beat by $120M or 3%"
- 解释结果为何与预期不同

### 3. 摘要格式
- 表格控制在 1-3 张，只做摘要，不做全套明细
- 不需要完整 P&L / Cash Flow / Balance Sheet，只列关键指标
- 默认读者已看过 initiation report

### 4. 引用与来源标注 ⭐⭐⭐ 强制要求

**CRITICAL**：所有数据都要用**具体来源**和**可点击超链接**进行标注。

**每个 figure 和 table 都要带具体引用，并附可点击链接：**

```
Source: Q3 2024 10-Q filed November 8, 2024; Company earnings release
        [Hyperlink "10-Q" to: https://www.sec.gov/cgi-bin/viewer?accession=...]
        [Hyperlink "earnings release" to: https://investor.company.com/news/q3-2024]
```

**在 Word 中，超链接应呈现为：**
- 文档名称显示为蓝色、带下划线的可点击链接
- 读者可以通过 Ctrl+Click 直接打开来源
- 不要使用纯文本 URL，要使用带显示文本的格式化超链接

**必须列出的来源：**

在每份 earnings update 中引用：
- ✅ Earnings release，附日期与 URL
- ✅ 10-Q filing，附 filing 日期和 EDGAR link
- ✅ Earnings call transcript，附日期
- ✅ Investor presentation / supplemental materials，如有
- ✅ Consensus estimates source，Bloomberg/FactSet 等，附日期
- ✅ Prior guidance，来自上一季度材料

**带可点击超链接的 REFERENCES SECTION：**

在报告末尾包含 "Sources" 部分：

```
SOURCES & REFERENCES

Earnings Materials (Q3 2024):
• Earnings Release (November 7, 2024)
  [Hyperlink entire line to: https://investor.company.com/news/q3-2024-earnings]

• Form 10-Q (Filed November 8, 2024)
  [Hyperlink to: https://www.sec.gov/cgi-bin/viewer?accession=...]

• Earnings Call Transcript (November 7, 2024)
  [Hyperlink to: https://seekingalpha.com/article/...]

• Investor Presentation (November 7, 2024)
  [Hyperlink to: https://investor.company.com/presentations/q3-2024.pdf]
```

**核对清单：**
- [ ] 每个 figure 都有具体文档和日期来源
- [ ] 每个 table 都有具体文档引用
- [ ] Beat/miss 分析注明一致预期来源和日期
- [ ] 指引变化注明当前和前次指引来源
- [ ] 关键统计数据有脚注
- [ ] Sources section 列出所有材料和 URL
- [ ] 所有 URL 都是可点击超链接，不是纯文本
- [ ] 所有 SEC filings 都超链接到 EDGAR viewer

### 5. 更新预测
- 基于结果更新前瞻预测
- 清楚展示 old vs. new estimates
- 解释变化内容及原因

## 高层工作流

业绩更新流程分为 5 个阶段：

### Phase 1: Data Collection（30-60 分钟）

**🚨🚨🚨 CRITICAL: TRAINING DATA IS OUTDATED 🚨🚨🚨**

**开始前，按顺序完成以下 4 步：**
1. **CHECK TODAY'S DATE**，写下当前日期
2. **SEARCH FOR LATEST**，用 web search 搜索："[Company] latest earnings results"
3. **VERIFY THE DATE**，确认业绩发布日期在最近 3 个月内
4. **CHECK TRANSCRIPT DATE**，确认 transcript 日期与发布日期一致

**常见错误**：直接使用训练数据中的旧业绩电话会，而不是搜索最新材料。

**要求：**
- ✅ 搜索最新业绩，不要依赖训练数据
- ✅ 写下今天日期和找到的发布日期
- ✅ 确认发布日期在今天之前 3 个月以内
- ✅ 确认 transcript 日期与发布日期一致
- ✅ 如果日期不匹配或过旧，超过 3 个月，继续重搜

**详见 [references/workflow.md](references/workflow.md)**，里面有详细搜索流程和验证步骤。

### Phase 2: Analysis（2-3 小时）
- 对每个关键指标做 beat/miss 分析
- 分部 / 地区 / 产品拆解
- 利润率和指引分析
- 更新财务模型和预测

**详见 [references/workflow.md](references/workflow.md)**，获取详细分析框架。

### Phase 3: Chart Generation（1-2 小时）
创建 8-12 张图，聚焦季度趋势和新增变化：
- 季度收入进展
- 季度 EPS 进展
- 季度利润率趋势
- 收入按分部 / 地区拆分
- 关键运营指标
- Beat/miss 总结
- 预测修订
- 估值图表

**详见 [references/workflow.md](references/workflow.md)**，查看图表规范。

### Phase 4: Report Creation（2-3 小时）
创建一份 8-12 页的 DOCX 报告，使用指定结构。

**详见 [references/report-structure.md](references/report-structure.md)**，其中包含完整的逐页模板和格式要求。

**高层结构：**
- 第 1 页：摘要，含评级和目标价
- 第 2-3 页：详细结果分析
- 第 4-5 页：关键指标与指引
- 第 6-7 页：更新后的投资论点
- 第 8-10 页：估值与预测
- 第 11-12 页：附录，可选

### Phase 5: Quality Check & Delivery（30 分钟）
在交付前验证内容、格式、准确性和时效性。

**详见 [references/best-practices.md](references/best-practices.md)**，里面有质检清单、常见错误和最佳实践。

## 输出规范

**主要交付物**：DOCX 报告，8-12 页
**文件名**：`[Company]_Q[Quarter]_[Year]_Earnings_Update.docx`
**示例**：`Nike_Q2_FY24_Earnings_Update.docx`

**内容包括：**
- 第 1 页：摘要，含评级、目标价、关键结论
- 第 2-3 页：详细结果分析
- 第 4-5 页：关键指标和指引
- 第 6-7 页：更新后的论点判断
- 第 8-10 页：估值和预测
- 第 11-12 页：附录，可选
- 8-12 张嵌入图表
- 1-3 张摘要表
- 带可点击超链接的完整 sources section

**可选交付物**：XLS 模型更新，业绩更新场景下为可选

## 与 Initiation Report 的关键区别

| Aspect | Earnings Update | Initiation Report |
|--------|----------------|-------------------|
| **Length** | 8-12 页 | 30-50 页 |
| **Words** | 3,000-5,000 | 10,000-15,000 |
| **Tables** | 1-3 张摘要表 | 12-20 张综合表 |
| **Figures** | 8-12 张 | 25-35 张 |
| **Turnaround** | 1-2 天 | 3-6 周 |
| **Scope** | 季度结果 | 完整公司覆盖 |
| **Focus** | 新变化 | 全面覆盖 |
| **Company Background** | 简略提及 | 6-10 页 |
| **XLS Model** | 可选 | 必需 |
