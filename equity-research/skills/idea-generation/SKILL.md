# Idea Generation

description: 系统化的股票筛选和投资想法挖掘。结合量化筛选、主题研究和模式识别，发掘新的 long 和 short 想法。适用于寻找新想法、运行筛选器或做主题扫面时。在用户提到 "idea generation"、"stock screen"、"find ideas"、"what looks interesting"、"screen for"、"new ideas" 或 "pitch me something" 时触发。

## 工作流

### 第 1 步：定义搜索条件

向用户确认参数：
- **Direction**：Long ideas、short ideas，还是两者都要
- **Market cap**：Large、mid、small、micro
- **Sector**：特定行业，还是跨行业
- **Style**：Value、growth、quality、special situation、event-driven
- **Geography**：US、international、global
- **Theme**：是否有特定主题角度，例如 AI、再工业化、老龄化等

### 第 2 步：量化筛选

根据风格运行筛选：

**Value Screen**
- P/E 低于行业中位数
- EV/EBITDA 低于历史均值
- Free cash flow yield >5%
- Price/book 低于 1.5x
- 最近 90 天有内部人买入
- 股息率高于市场平均

**Growth Screen**
- Revenue growth >15% YoY
- Earnings growth >20% YoY
- 收入增速加快
- 利润率扩张
- 高资本回报率，>15%
- 强劲净留存率，SaaS 通常 >110%

**Quality Screen**
- 持续稳定的收入增长，5 年以上
- 稳定或扩张的利润率
- ROE >15%
- 低 debt/equity
- 高 free cash flow 转化率
- 内部人持股 >5%

**Short Screen**
- 收入下滑或增速放缓
- 利润率压缩
- 应收账款 / 存货相对销售额上升
- 内部人卖出
- 相对同行有估值溢价但缺乏支撑
- 高 short interest 且基本面恶化
- 会计预警信号，审计师变更、重述

**Special Situation Screen**
- 近 12 个月上市的 IPO / SPAC，且存在解禁
- 近 12 个月 spin-off
- 刚完成重组的公司
- 激进投资者介入
- 业绩不佳公司的管理层变动

### 第 3 步：主题扫面

对于主题型想法，先研究主题，再识别受益者：

1. 定义主题论点，例如 "AI infrastructure spending accelerates through 2026"
2. 绘制价值链，谁是直接受益者，谁是间接受益者
3. 区分纯主题标的与分散敞口标的
4. 判断哪些名字已经被市场充分定价，哪些仍被低估
5. 寻找市场尚未充分关联到该主题的二阶受益者

### 第 4 步：想法呈现

对每一个通过筛选的想法，按以下格式呈现：

**[Company Name] — [Long/Short] — [One-Line Thesis]**

| Metric | Value | vs. Peers |
|--------|-------|-----------|
| Market cap | | |
| EV/EBITDA (NTM) | | |
| P/E (NTM) | | |
| Revenue growth | | |
| EBITDA margin | | |
| FCF yield | | |

**Thesis（3-5 bullets）：**
- 为什么这里存在错价
- 市场忽略了什么
- 哪个催化剂会推动价值兑现

**Key Risks：**
- 什么情况会让这个判断失效

**Suggested Next Steps：**
- 建完整模型？做深度尽调？安排专家访谈？

### 第 5 步：输出

- 5-10 个想法的 shortlist，每个附一页摘要
- 记录筛选条件和方法论
- 所有想法的横向对比表
- 排序后的优先级清单，哪些应优先深入研究

## 重要说明

- 筛选器产生的是候选标的，不是结论，每个输出都需要进一步做基本面工作
- 最好的想法往往来自交叉点，例如高质量公司因短期逆风而跌到价值价位
- 避免拥挤交易，要检查持仓结构、short interest 以及覆盖该公司的分析师数量
- 逆向想法必须有催化剂，没有催化剂的提前布局，往往和做错没有区别
- 长期跟踪想法命中率，哪些筛选器和方法最有效
- Short 想法需要更高信心，时点更难，风险收益也更不对称
