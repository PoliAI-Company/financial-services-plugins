# 可比公司分析

## ⚠️ 关键：数据源优先级（先读）

**始终遵循以下数据源层级：**

1. **优先检查 MCP 数据源**。如果可用 S&P Kensho MCP、FactSet MCP 或 Daloopa MCP，则只使用它们获取财务和交易信息。
2. 如果上述 MCP 数据源可用，**不要使用网页搜索**。
3. **仅在 MCP 不可用时**，再使用 Bloomberg Terminal、SEC EDGAR 文件或其他机构级来源。
4. **绝不要把网页搜索当作主要数据源**，因为它缺乏机构级分析要求的准确性、审计轨迹和可靠性。

**为什么重要：** MCP 来源提供经验证的机构级数据，并附带合适引用。网页搜索结果可能过时、不准确或不可靠。

---

## 概览

这个 skill 教 Claude 构建机构级的可比公司分析，把经营指标、估值倍数和统计基准结合起来。输出是结构化的 Excel/电子表格，帮助通过同行比较支持投资判断。

关于示例文件、结构搭建、公式优先于硬编码、统计区块、估值倍数、Notes & Methodology、指标选择框架、最佳实践、常见错误、示例模板布局、红旗项、Excel 公式参考、输出检查清单与持续改进流程，沿用原始结构和公式，所有 Excel 公式、代码块、表格、路径和引用形式保持不变，供中文读者直接使用。

**核心原则：** 先搭好正确结构，再让数据自己讲故事。

**关键要求：**
- 所有派生值必须是 Excel 公式，而不是硬编码
- 分步向用户展示结构、输入、经营指标、估值倍数和统计区块
- 所有硬编码输入都要有来源注释
- 统计区块应覆盖可比指标，不覆盖纯规模型指标
- 输出必须具有机构级质量，而不是仅仅“看起来像机构模板”
