## 模板要求

**这个 skill 使用模板来构建 LBO 模型。必须先检查是否附带模板文件。**

在开始任何 LBO 模型前：
1. **如果附带了模板文件**：严格按模板结构使用它，复制并用用户数据填充
2. **如果没有附带模板**：询问用户是否有指定模板，否则可以使用标准模板
3. **如果使用标准模板**：复制 `examples/LBO_Model.xlsx` 作为起点，并填入用户假设

**重要：** 如果附带了像 `LBO_Model.xlsx` 这样的文件，就必须用它作为模板，不要从零开始。

## 关键说明

- 在 Excel 内运行时使用 Office JS，生成独立 `.xlsx` 时使用 Python/openpyxl
- 每个计算都必须是 Excel 公式，不允许把 Python 计算结果硬编码回单元格
- 使用模板既有结构，不要自创布局
- 保持符号约定一致
- 分 section 工作，并在每个 section 完成后向用户展示、验证并获得确认

## 核心格式规范

- **Blue**：硬编码输入
- **Black**：计算公式
- **Purple**：同一标签页内的直接链接
- **Green**：跨标签页引用

填充底色默认使用蓝灰配色，并保留原模板优先权。

## 工作方法

1. 先分析模板结构、时间线、输入格与公式格、已有公式和模板惯例
2. 按层级判断每个需要填写公式的单元格：先看模板，再看用户要求，最后才是标准做法
3. 特别注意平衡项、税项、利息与循环引用、债务偿还 waterfall、IRR/MOIC 和 sensitivity tables
4. 完成后运行验证清单，包括平衡检查、现金流检查、债务 schedule、回报分析、敏感性表和格式检查

所有代码块、公式模式、验证清单、常见错误表和 section-by-section checkpoints 保持原文结构，可直接参照执行。
