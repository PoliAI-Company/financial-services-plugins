# 客户回顾会议准备

description: 为客户回顾会议做准备，包含组合表现摘要、配置分析、沟通要点和行动项。将账户数据整合为简洁、可直接用于会议的材料。适用于季度回顾、年度 checkup，或临时客户会议前。触发词包括 "client review"、"meeting prep for [client]"、"quarterly review"、"prep for [client name]" 或 "client meeting"。

## Workflow

### Step 1: 客户背景

收集或查找：
- **Client name** 及家庭成员
- **Account types**：Taxable、IRA、Roth、401(k)、trust 等
- **Total AUM**，跨账户总 AUM
- **Investment Policy Statement (IPS)**：目标配置、风险承受能力、限制条件
- **Life stage**：积累期、准退休、退休、传承阶段
- **Last meeting date** 及未完成行动项

### Step 2: 投资组合表现

按单个账户和家庭汇总口径展示：

| Metric | QTD | YTD | 1-Year | 3-Year | Since Inception |
|--------|-----|-----|--------|--------|----------------|
| Portfolio return | | | | | |
| Benchmark return | | | | | |
| Alpha | | | | | |

**Performance Attribution：**
- 哪些资产类别 / 持仓贡献了回报
- 前 3 大正贡献者和前 3 大负贡献者
- 是否有单一持仓带来异常大的影响

### Step 3: 配置审查

当前配置 vs. 目标配置：

| Asset Class | Target | Current | Drift | Action |
|------------|--------|---------|-------|--------|
| US Large Cap | | | | |
| US Mid/Small | | | | |
| International Developed | | | | |
| Emerging Markets | | | | |
| Fixed Income | | | | |
| Alternatives | | | | |
| Cash | | | | |

标记任何超过 IPS 再平衡阈值的偏移，通常为 3-5%。

### Step 4: 沟通要点

生成会议议程：

1. **Market overview**，2-3 分钟，简要宏观背景和展望
2. **Portfolio performance**，5 分钟，我们表现如何，原因是什么
3. **Allocation review**，5 分钟，是否需要再平衡
4. **Planning updates**，5-10 分钟：
   - 是否有生活变化，工作、健康、家庭、住房、教育
   - 收入需求是否变化
   - 税务情况更新
   - 遗产规划更新
5. **Action items**，5 分钟，下次会议前我们要做什么

### Step 5: 主动建议

根据回顾结果，建议：
- 再平衡交易，如偏移超过阈值
- 税损收割机会
- 现金部署或提款规划
- Roth conversion 机会，如适用
- 受益人更新或遗产规划需求
- 保险审查，寿险、伤残险、LTC

### Step 6: 输出

- 一页式客户回顾摘要，Word 或 PDF
- 带 benchmark 的表现表
- 配置饼图，当前 vs. 目标
- 建议行动项
- 会议议程

## Important Notes

- 会前一定要充分了解客户，先复习上次会议记录
- 先讲客户真正关心的，不要只讲你自己想讲的
- 如果表现不好，要直接说明，不要回避或粉饰
- 结尾始终给出明确的行动项、下一步和日期
- 记录会议纪要以及对 IPS 的任何更改
- 合规要求，确保所有材料符合机构政策和监管要求
