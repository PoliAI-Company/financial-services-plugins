# 尽调清单

description: 生成并跟踪全面的 due diligence checklist，可根据目标公司的行业、交易类型和复杂程度定制。覆盖主要工作流，包括资料请求清单、状态跟踪和红旗升级。适用于尽调启动、组织数据室审阅，或跟踪未完成事项。触发词包括 "dd checklist"、"due diligence tracker"、"diligence request list"、"what do we still need" 或 "data room review"。

## 工作流

### 第 1 步：确定尽调范围

向用户询问：
- **Target company**：名称、行业、业务模式
- **Deal type**：平台收购、add-on、growth equity、recap、carve-out
- **Deal size / complexity**：决定尽调深度
- **Key concerns**：任何已知优先问题，如客户集中度、监管、环境等
- **Timeline**：LOI / close 目标时间是什么时候

### 第 2 步：生成各工作流清单

根据行业特点，为主要工作流生成定制化清单：

**Financial Due Diligence**
- 盈利质量（QoE），收入和 EBITDA 调整
- 营运资金分析，正常化水平 vs. 实际水平
- 债务与类债务项目
- 资本开支，维护性 vs. 增长性
- 税务结构与税务风险敞口
- 审计历史与会计政策
- Pro forma 调整，run-rate、synergies

**Commercial Due Diligence**
- 市场规模与增长，TAM / SAM / SOM
- 竞争定位与市场份额
- 客户分析，集中度、留存、NPS
- 定价能力与合同结构
- 销售 pipeline 与 backlog
- Go-to-market 效率

**Legal Due Diligence**
- 公司结构和组织架构图
- 重要合同，客户、供应商、合作伙伴
- 诉讼历史与待决索赔
- IP 资产组合与保护情况
- 监管合规
- 雇佣协议和竞业限制

**Operational Due Diligence**
- 管理团队评估
- 组织架构与关键岗位风险
- IT 系统和基础设施
- 供应链和供应商依赖
- 设施和不动产
- 保险覆盖

**HR / People Due Diligence**
- 组织结构图和 headcount 趋势
- 薪酬 benchmark
- 福利和养老金义务
- 关键员工流失风险
- 文化评估
- 工会 / 劳动协议

**IT / Technology Due Diligence**（适用于技术驱动型业务）
- 技术栈和架构
- 技术债务评估
- 网络安全态势
- 数据隐私合规，GDPR、CCPA、SOC2
- 产品路线图与 R&D 支出
- 可扩展性评估

**Environmental / ESG**（如适用）
- 环境责任
- 监管合规历史
- ESG 风险与机会

### 第 3 步：状态跟踪

对每个项目跟踪：

| 项目 | 工作流 | 优先级 | 状态 | 负责人 | 备注 |
|------|-----------|----------|--------|-------|-------|
| QoE report | Financial | P0 | Pending | | |
| Customer interviews | Commercial | P0 | In Progress | | 3 of 10 complete |

状态选项：Not Started → Requested → Received → In Review → Complete → Red Flag

### 第 4 步：红旗汇总

持续维护尽调中发现的红旗清单：
- 发现了什么
- 属于哪个工作流
- 严重程度，deal-breaker / significant / manageable
- 缓释措施或解决路径
- 对估值或交易条款的影响

### 第 5 步：输出

- Excel 工作簿，默认按工作流拆分 tab
- 汇总仪表盘，按工作流展示完成率、未完成事项、红旗
- 供 deal team 使用的每周状态更新格式

## Sector-Specific Additions

根据行业自动加入相关项目：
- **Software/SaaS**：ARR 质量、cohort analysis、hosting costs、SOC2
- **Healthcare**：监管批准、报销风险、payor mix
- **Industrial**：设备状况、环境修复、安全记录
- **Financial services**：监管资本、合规历史、信贷质量
- **Consumer**：品牌健康度、渠道结构、季节性、库存管理

## Important Notes

- 优先处理阻碍 LOI 或 close 的 P0 项目
- 卖方响应慢的项目要特别标记，这可能本身就是问题信号
- 将数据室内容与清单交叉核对，识别缺口
- 随着尽调推进不断更新清单，它是一个动态文档
