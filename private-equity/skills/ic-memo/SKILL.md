# 投资委员会备忘录

description: 为 PE 交易审批起草结构化的投资委员会备忘录。将尽调发现、财务分析和交易条款整合为专业、可供 IC 使用的文档。适用于准备投资委员会会议、整理交易材料，或形成正式推荐意见。触发词包括 "write IC memo"、"investment committee memo"、"deal write-up"、"prepare IC materials" 或 "recommendation memo"。

## Workflow

### Step 1: 收集输入

从用户处收集，或从本次会话中已有分析里提取：

- 公司概览与业务描述
- 行业 / 市场背景
- 历史财务数据（3-5 年）
- 管理层评估
- 交易条款（价格、结构、融资）
- 尽调发现（商业、财务、法务、运营）
- 价值创造计划 / 100 天计划
- 回报分析（基准、上行、下行情景）

### Step 2: 备忘录结构

标准 IC memo 结构：

**I. Executive Summary**（1 页）
- 公司描述、交易逻辑、关键条款
- 推荐意见与核心回报指标
- 前 3 大风险及缓释措施

**II. Company Overview**（1-2 页）
- 业务描述、产品 / 服务
- 客户基础与 go-to-market 模式
- 竞争定位
- 管理团队

**III. Industry & Market**（1 页）
- 市场规模与增长
- 竞争格局
- 长期趋势 / 顺风因素
- 监管环境

**IV. Financial Analysis**（2-3 页）
- 历史表现，收入、EBITDA、利润率、现金流
- 盈利质量调整
- 营运资金分析
- Capex 需求

**V. Investment Thesis**（1 页）
- 为什么这是一笔有吸引力的投资，3-5 个支柱
- 价值创造杠杆，organic growth、margin expansion、M&A、multiple expansion
- 前 100 天优先事项

**VI. Deal Terms & Structure**（1 页）
- 企业价值与隐含倍数
- Sources & uses
- 资本结构 / 杠杆
- 核心法律条款

**VII. Returns Analysis**（1 页）
- 基准、上行和下行情景
- 各情景下的 IRR 和 MOIC
- 驱动回报的关键假设
- 敏感性分析

**VIII. Risk Factors**（1 页）
- 按严重程度和发生概率排序的关键风险
- 每项风险的缓释措施
- Deal-breaker 风险，如有

**IX. Recommendation**
- 明确建议：Proceed / Pass / Conditional proceed
- 关键条件或后续步骤

### Step 3: 输出格式

- 默认：带专业排版的 Word 文档（.docx）
- 备选：Markdown，便于快速审阅
- 财务和回报部分要包含表格，不要只有文字

## Important Notes

- IC memo 应当客观、平衡，如实呈现 bull case 和 bear case
- 不要弱化风险，IC 成员最终都会看到，可信度更重要
- 如果用户提供了机构标准模板，就使用该模板
- 财务表必须勾稽一致，检查 EBITDA bridge、S&U balance 和回报测算是否统一
- 对于缺失输入，优先询问，不要自行假设交易条款或回报
